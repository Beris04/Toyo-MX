Corrección aplicada - comentarios en pedidos digitales

Problema detectado:
- En celular, el campo Comentarios se capturaba en la hoja móvil, pero al descargar el pedido el sistema leía primero el campo del resumen web/escritorio.
- Eso hacía que el pedido descargado apareciera como "Sin comentarios", aunque el cliente sí los hubiera escrito.

Corrección:
- Se agregó sincronización automática entre vista móvil y vista web antes de descargar.
- El pedido ahora toma siempre el comentario real del campo visible o del campo activo.
- Se guarda también en localStorage para conservarlo si el cliente cierra y vuelve a abrir.
- Se actualizó la versión del script a v=20260518comentarios1 para evitar caché en GitHub Pages.

Archivo clave modificado:
- pedido_assets/pedido_app_reset.js

Recomendación:
- Subir todo el ZIP completo a la raíz del repositorio en GitHub Desktop.
- Hacer Commit y Push.
- Probar en celular agregando un comentario y descargando el pedido.
