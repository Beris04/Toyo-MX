RECOMENDADO PARA TU REPO

El problema no se arregla adivinando mayúsculas desde el index.
La solución correcta es:

1) En tu repo local, copia "reconstruir_clients_json.py" a la raíz del proyecto.
2) Abre terminal dentro del repo.
3) Ejecuta:
   python reconstruir_clients_json.py

Esto va a generar un clients.json NUEVO respetando exactamente:
- nombre real de la carpeta
- nombre real del archivo HTML
- mayúsculas y minúsculas tal como existen

4) Reemplaza tu index por "index_respetando_case.html" renombrándolo a:
   index.html

5) Haz commit y push.

Resultado:
- el index abrirá la ruta EXACTA
- ya no intentará convertir a minúsculas
- GitHub Pages dejará de romper clientes por el case
